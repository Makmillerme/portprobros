# audit

Перевірка **Next.js** на проблеми **продуктивності**, **hydration**, меж **сервер/клієнт** (RSC, `"use client"`) для поточного контексту маршруту або змін.

## Що зробити

1. Якщо підключено **next-devtools** MCP — виконай скан/діагностику згідно з доступними інструментами сервера.
2. Якщо MCP недоступний — ревʼю коду сторінки/layout, меж компонентів, + перегляд **логів терміналу** / помилок збірки (див. `senior-agent-workflow.mdc`).
3. Звітуй знайдене та пропозиції виправлень; критичні правки — після **`/serena`** у **Agent**.

Місце в пайплайні: [`.cursor/rules/senior-agent-workflow.mdc`](../rules/senior-agent-workflow.mdc) (розділ «Команда `/audit`»).

Ця команда доступна в чаті як /audit
