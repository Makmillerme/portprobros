# docs

Актуальна документація під **версії залежностей проєкту** (орієнтир — 2026+ практики та офіційні джерела).

## Що зробити

1. Визнач бібліотеку / API з контексту задачі; прочитай **релевантну версію** у [`nextjs_vmd/package.json`](../../nextjs_vmd/package.json) (або іншого пакета в монорепо).
2. Відкрий **офіційну** документацію через **`WebFetch`** за стабільним URL; додатково `web_search` для реліз-нот і невідповідностей версій.
3. Коротко зафіксуй факти, потрібні для рішення; застосуй до коду / плану без здогадок.

Місце в пайплайні: [`.cursor/rules/senior-agent-workflow.mdc`](../rules/senior-agent-workflow.mdc) (розділ «Команда `/docs`»).
